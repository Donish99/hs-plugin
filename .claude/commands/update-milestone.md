# Update Milestone Progress

Mark completed items in milestone files after finishing work.

## Instructions

Based on the work just completed:

1. Identify which milestone file(s) are affected
2. Find the specific checkbox items that were completed
3. Update `[ ]` to `[x]` for completed items
4. Add any implementation notes if the approach differed from the plan
5. Check if any acceptance criteria are now met

## Usage

After completing any feature or task:
- Specify what was completed
- Claude will update the relevant milestone file(s)

## Example

User: "I just finished implementing the OAuth callback handler"

Claude will:
1. Open `milestones/01-foundation.md`
2. Mark relevant items complete under "1.5 OAuth Flow Implementation"
3. Report updated progress
