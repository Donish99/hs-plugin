# Implement Feature from Milestone

Implement a specific feature following the project plan.

## Instructions

1. First, check the current milestone status
2. Read the relevant milestone file for implementation details
3. Review the master plan (`plan.md`) for technical specifications
4. Follow the project's code standards from `CLAUDE.md`
5. Implement the feature
6. Update the milestone file to mark items complete
7. Report what was implemented and any deviations from plan

## Process

### Before coding:
- Read the milestone file section for the feature
- Check `plan.md` for API details, schemas, code examples
- Review existing code patterns in the project

### During coding:
- Follow NestJS conventions
- Add proper TypeScript types
- Include error handling
- Add comments for complex logic

### After coding:
- Update milestone checkboxes
- List any follow-up tasks discovered
- Note any plan deviations

## Usage

Specify which feature to implement:
- By milestone number and section: "Implement milestone 1, section 1.5"
- By feature name: "Implement OAuth callback handler"
- By next available: "Implement next feature"
